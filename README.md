# 电影放映授权编排库

本服务用于影片拷贝、字幕、授权和放映发布。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：影片、拷贝、字幕版本、授权合同、场次、借运交接、研究访问、发布游标。

发布时原子校验授权、位置、字幕和场地；授权修订产生影响事件；迟到交接按发生时间重建位置；下游按游标续传。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/screening_rights.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
